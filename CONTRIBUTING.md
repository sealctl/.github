# Contributing

Thanks for your interest in sealctl.

**Issues are welcome:** bug reports, questions and ideas, on the issues of the repository they
concern, for example [sealctl/sealctl](https://github.com/sealctl/sealctl/issues).

**Security reports are welcome**, privately: see the [security policy](SECURITY.md). Never in a
public issue.

**Code pull requests are not accepted for now.** The terms for outside contributions (a
contributor licence agreement, and an AGPL section 7 permission for the phone app, which also
ships through the app stores) are not settled yet, so pull requests can only be opened by
maintainers. This file will say when that changes.
